# gpu0 native raw records

All JSON samples, status files, logs, and the command ledger are in [the gpu0 archive](../../raw/gpu0.tar.gz). Extract it from the report directory with:

```bash
tar -xzf raw/gpu0.tar.gz
```

Extraction restores the original `gpu0/native/` and `gpu0/vllm/` paths for the supplied aggregators.
