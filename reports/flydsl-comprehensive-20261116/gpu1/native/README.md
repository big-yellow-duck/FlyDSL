# gpu1 native raw records

All JSON samples, status files, logs, and the command ledger are in [the gpu1 archive](../../raw/gpu1.tar.gz). Extract it from the report directory with:

```bash
tar -xzf raw/gpu1.tar.gz
```

Extraction restores the original `gpu1/native/` and `gpu1/vllm/` paths for the supplied aggregators.
